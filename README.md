# 📚 Glossaire Vibe Coding — Application Web Interactive

Application web responsive et mobile-first regroupant les **57 notions clés** de la formation Vibe Coding (Modules 1 à 4).

## 🚀 Fonctionnalités
- **Recherche instantanée** par mot-clé ou début de mot (Word Boundary)
- **Index alphabétique A-Z**
- **Filtres par Modules** (M1 à M4) et par **Thématiques**
- **Panneau de filtres repliable**
- **Définitions V2 simplifiées** adaptées aux débutants
- **Design système Vibe Coding** (Charte officielle)

## 🛠️ Mise à jour du Glossaire
Pour modifier ou ajouter des termes :
1. Éditer le fichier `glossaire_formation_vibe_coding.md`.
2. Exécuter le script de génération :
   ```bash
   python3 scripts/build_interactive_web_glossary.py
   ```
