# 📚 Glossaire Officiel de la Formation Vibe Coding

Ce glossaire regroupe le vocabulaire technique des **Modules 1 à 4**, trié par **ordre alphabétique**, avec un format de référence de leçon rigoureusement homogène (`CODE — TITRE`).

| Mot / Concept | Statut | Type de terme | Définition | Référence de la leçon |
| :--- | :--- | :--- | :--- | :--- |
| **AGENTS.md** | `Défini` | `Fichier de contexte / Méthode` | Fichier texte situé à la racine d'un projet, regroupant les consignes, les technologies autorisées et les règles de travail strictes à faire respecter par l'agent IA. | M4C3L1 — La gestion des agents IA dans un IDE local |
| **Antigravity** | `Défini` | `IDE / Agent SOTA` | Éditeur de code intelligent sur ordinateur permettant de piloter des assistants IA autonomes et d'exécuter des séquences de travail avancées. | M4C1L1 — Découvrir les bases d'Antigravity |
| **API (Application Programming Interface)** | `Défini` | `Architecture` | Passerelle et ensemble de règles permettant à deux applications ou services informatiques de communiquer et d'échanger des informations automatiquement. | M4C4L4 — Connecter l'interface Front-end au serveur local |
| **Bac à sable (sandboxing)** | `Non défini (Cité)` | `Sécurité / IDE` | Zone d'exécution isolée et sécurisée qui limite les accès réseau et ordinateur d'une IA afin d'éviter toute commande dangereuse. | M1C4L5 — Mettre en place une routine de veille efficace |
| **Back-end** | `Défini` | `Architecture` | Coulisses et partie serveur d'une application, chargées du traitement des données, des règles internes et des échanges avec la base de données. | M1C3L1 — Différencier le Front-end et le Back-end |
| **Bolt.new** | `Défini` | `Outil / Plateforme` | Outil de création d'applications web utilisable dans le navigateur, permettant de générer et tester un projet complet directement en ligne. | M2C3L1 — Prise en main de Bolt.new |
| **Branche Git** | `Défini` | `Concept Git` | Copie parallèle du projet permettant de développer et tester une nouveauté en toute sécurité sans modifier la version principale. | M4C4L7 — Maîtriser Git local (Commits & Branches) |
| **Browser agent** | `Défini` | `Outil IA` | Assistant IA capable de naviguer seul sur le web, d'interagir avec les éléments d'une page et de vérifier le fonctionnement d'une interface. | M4C3L6 — Comprendre et utiliser un Browser Agent |
| **Claude 3.5 Sonnet** | `Défini` | `Modèle IA` | Modèle d'intelligence artificielle développé par Anthropic, très performant pour la rédaction de code et la résolution de problèmes complexes. | M3C2L1 — Prise en main de Cursor pour le mobile |
| **Commit** | `Défini` | `Concept Git` | Sauvegarde horodatée de l'état du code source à un instant précis, accompagnée d'un message expliquant le changement effectué. | M4C1L8 — Réaliser ses premiers commits avec l'agent |
| **Composant UI** | `Défini` | `Concept web` | Élément visuel autonome et réutilisable dans une interface (ex. : bouton, carte d'information, formulaire). | M2C2L3 — Modifier et affiner le design en langage naturel |
| **Contexte (context window)** | `Défini` | `Concept IA` | Quantité maximale de mémoire (mesurée en tokens) qu'une IA peut lire et conserver en tête au cours d'une même session. | M1C2L3 — Gérer le contexte et la mémoire de l'agent |
| **Cross-platform** | `Défini` | `Architecture` | Capacité d'un même projet de code à fonctionner sans réécriture sur plusieurs systèmes (iOS, Android, web). | M3C1L1 — Introduction à la création d'applications mobiles |
| **CSS (Cascading Style Sheets)** | `Défini` | `Langage` | Langage responsable du style visuel des pages web, gérant les couleurs, la typographie et la disposition des éléments. | M1C3L3 — Les bases du CSS |
| **Cursor** | `Défini` | `IDE / Outil` | Logiciel d'édition de code sur ordinateur qui intègre directement des assistants IA pour créer, corriger et faire évoluer des projets. | M3C2L1 — Prise en main de Cursor pour le mobile |
| **DOM (Document Object Model)** | `Défini` | `Concept web` | Structure organisée d'une page web que le langage JavaScript peut lire et modifier en temps réel (textes, boutons, affichage). | M1C3L4 — Les bases du JavaScript |
| **Dépôt Git (repository)** | `Non défini (Cité)` | `Concept Git` | Dossier de projet suivi par Git, qui conserve la totalité des fichiers, de l'historique des sauvegardes et des branches. | M1C1L4 — Découvrir l'écosystème Git et GitHub |
| **Endpoint** | `Défini` | `Architecture / Web` | Adresse web spécifique d'une API permettant à une application d'envoyer ou de demander une donnée précise au serveur. | M4C4L4 — Connecter l'interface Front-end au serveur local |
| **.env (.env.local)** | `Défini` | `Sécurité / Configuration` | Fichier texte confidentiel servant à stocker les clés d'accès (API) et les réglages secrets à l'écart du code public. | M4C4L5 — Isoler ses secrets et variables locales dans .env.local |
| **Expo** | `Défini` | `Outil / Framework` | Ensemble d'outils simplifiant la création, le test et la publication d'applications mobiles développées avec React Native. | M3C1L2 — Découvrir l'écosystème Expo & React Native |
| **Express.js** | `Défini` | `Framework backend` | Outil côté serveur pour Node.js facilitant la création de passerelles (API) et la gestion des chemins de navigation web. | M4C4L3 — Générer son premier serveur local (Node.js/Express) |
| **Front-end** | `Défini` | `Architecture` | Interface visuelle et partie écran d'une application, directement visible et manipulable par l'utilisateur. | M1C3L1 — Différencier le Front-end et le Back-end |
| **Git** | `Défini` | `Outil / VCS` | Outil de suivi de version qui enregistre chaque évolution du code et permet d'annuler ou de comparer les modifications. | M4C1L8 — Sauvegarder son travail avec Git |
| **GitHub** | `Défini` | `Plateforme / Cloud` | Service en ligne permettant d'héberger des projets Git sur internet, de les sauvegarder à distance et de travailler à plusieurs. | M4C1L8 — Sauvegarder son travail avec Git |
| **.gitignore** | `Non défini (Cité)` | `Fichier de config Git` | Fichier indiquant à Git les documents temporaires, clés confidentielles ou dossiers lourds à ne jamais inclure dans les sauvegardes. | M2C5L3 — Bannir les clés API et secrets de ses prompts |
| **Hallucination IA** | `Défini` | `Concept IA / Risque` | Situation où une IA invente des réponses, des lignes de code ou des noms d'outils inexacts tout en paraissant certaine d'elle-même. | M1C2L5 — Identifier les pièges et limites de l'IA |
| **HTML (HyperText Markup Language)** | `Défini` | `Langage` | Langage de base définissant la structure et le contenu d'une page web (titres, textes, images, liens). | M1C3L2 — Les bases du HTML |
| **HTTP / HTTPS** | `Non défini (Cité)` | `Protocole web` | Règles de communication du web régissant l'échange d'informations entre le navigateur et le serveur (version HTTPS sécurisée et chiffrée). | M1C3L5 — Comprendre le réseau et les requêtes web |
| **IA générative (LLM)** | `Défini` | `Concept IA` | Intelligence artificielle entraînée sur de vastes volumes de données, capable de comprendre et de produire du texte ou du code sur demande. | M1C1L3 — Comprendre le rôle de l'IA dans la création de logiciels |
| **IDE agentique** | `Défini` | `Concept / Outil` | Logiciel de création de code où l'IA peut lire le projet, créer des fichiers et exécuter elle-même des commandes système. | M4C1L2 — Pourquoi utiliser un IDE agentique local ? |
| **Injection SQL** | `Défini` | `Sécurité web` | Faille de sécurité consistant à piéger un formulaire en y saisissant du code malveillant pour pirater la base de données. | M2C5L6 — La chaîne de confiance et la sécurité |
| **JavaScript (JS)** | `Défini` | `Langage` | Langage de programmation rendant les pages web interactives et capables de réagir aux actions (clics, animations, calculs). | M1C3L4 — Les bases du JavaScript |
| **JSON (JavaScript Object Notation)** | `Défini` | `Format de données` | Format texte standardisé permettant d'échanger des données lisibles sous la forme de clés et de valeurs (ex. : `nom: "Jean"`). | M1C3L4 — Les bases du JavaScript |
| **Layout / flexbox** | `Défini` | `Concept web / Mobile` | Système de disposition en CSS facilitant l'alignement, le centrage et l'espacement des éléments sur un écran. | M3C3L1 — Concevoir l'interface mobile |
| **Localhost & port réseau** | `Non défini (Cité)` | `Réseau local` | Adresse de son propre ordinateur (localhost) et numéro de porte virtuelle (port) servant à tester une application avant sa mise en ligne. | M1C4L6 — Comprendre et utiliser le terminal |
| **Logs d'erreur** | `Défini` | `Débogage` | Journal enregistrant au fur et à mesure les événements, avertissements et dysfonctionnements survenus dans une application. | M4C4L6 — Déboguer la chaîne Front-Back et lire les logs |
| **Lovable** | `Défini` | `Outil / Plateforme` | Outil en ligne de Vibe Coding qui permet de générer et modifier des applications web complètes en discutant en français. | M2C2L1 — Prise en main de Lovable |
| **Mode chat** | `Défini` | `Mode IDE` | Mode de discussion où l'on pose des questions à l'IA ou demande une explication sans modifier directement les fichiers. | M4C2L3 — Le mode Chat |
| **Mode composer** | `Défini` | `Mode IDE` | Mode de travail où l'agent IA agit directement sur le projet en créant ou modifiant lui-même les fichiers de code. | M4C2L4 — Le mode Composer |
| **Mode plan** | `Défini` | `Mode IDE` | Mode de cadrage dans lequel l'agent IA établit une feuille de route étape par étape avant d'entamer la création du code. | M4C2L6 — Le mode Plan |
| **No-code / low-code** | `Défini` | `Méthode` | Méthodes de création d'applications reposant sur des outils visuels qui réduisent ou éliminent le besoin de coder à la main. | M2C1L1 — Comparatif des plateformes de Vibe Coding Web |
| **Node.js** | `Défini` | `Environnement d'exécution` | Outil permettant d'exécuter du code JavaScript en coulisses sur un serveur ou un ordinateur, en dehors d'un simple navigateur web. | M4C4L3 — Générer son premier serveur local (Node.js/Express) |
| **Prompt engineering** | `Défini` | `Méthode` | Art de concevoir et d'affiner des instructions claires pour guider précisément les réponses d'une intelligence artificielle. | M1C2L1 — Découvrir l'art du Prompt Engineering |
| **Prompt zero** | `Défini` | `Méthode prompting` | Instruction de départ définissant l'objectif, les technologies retenues et les règles fondamentales avant de démarrer la création d'un projet. | M2C3L4 — Découvrir le Prompt Zero |
| **Prompting** | `Défini` | `Méthode` | Action de formuler des consignes écrites pour demander un résultat précis à une intelligence artificielle. | M1C1L2 — Qu'est-ce que le Vibe Coding ? |
| **RAG (Retrieval-Augmented Generation)** | `Non défini (Cité)` | `Concept IA` | Méthode fournissant automatiquement des documents ou du code réel à l'IA avant qu'elle ne réponde, afin de garantir des informations exactes. | M1C4L3 — L'injection de contexte et la documentation |
| **React** | `Défini` | `Framework / Bibliothèque` | Outil populaire créé par Meta pour construire des interfaces web dynamiques en les découpant en éléments réutilisables. | M2C2L2 — Générer sa première application web avec Lovable |
| **React Native** | `Défini` | `Framework` | Outil créé par Meta permettant de fabriquer des applications mobiles pour iPhone (iOS) et Android en utilisant du code JavaScript. | M3C1L1 — Introduction à la création d'applications mobiles |
| **Refactorisation (refactoring)** | `Non défini (Cité)` | `Méthode de code` | Réorganisation et nettoyage du code source pour le rendre plus lisible et mieux structuré, sans en changer le fonctionnement visuel. | M4C5L2 — Refactoriser son code avec l'agent |
| **Responsive design** | `Défini` | `Méthode / Design` | Technique d'aménagement visuel permettant à un site de s'adapter automatiquement à la taille des écrans (smartphone, tablette, ordinateur). | M2C2L3 — Modifier et affiner le design |
| **SKILL (compétence agent)** | `Défini` | `Extension IA` | Module complémentaire ou guide d'instructions ajoutant une capacité spécialisée à un agent IA pour une mission donnée. | M4C3L8 — Comprendre et utiliser des SKILLS |
| **Sous-agent (subagent)** | `Défini` | `Concept IA` | Second assistant IA démarré en arrière-plan pour accomplir une mission précise sans interrompre le travail principal. | M4C3L4 — Les sous-agents et la parallélisation de tâches |
| **Tailwind CSS** | `Défini` | `Framework CSS` | Outil de mise en forme permettant d'appliquer rapidement du style sur des éléments web grâce à des étiquettes prêtes à l'emploi. | M2C2L2 — Générer sa première application web me avec Lovable |
| **Terminal / CLI** | `Défini` | `Outil / Interface` | Fenêtre textuelle permettant de donner des ordres directs à son ordinateur ou à ses outils en tapant des lignes de commande. | M4C1L6 — Comprendre le terminal & les commandes clés |
| **Token** | `Défini` | `Concept IA / Métrique` | Morceau de texte de quelques lettres servant d'unité de compte pour la mémoire d'une IA (1 000 tokens représentent environ 750 mots). | M1C2L3 — Gérer le contexte et la mémoire de l'agent |
| **v0 (by Vercel)** | `Défini` | `Outil / Plateforme` | Outil web d'IA conçu par Vercel, capable de générer instantanément le code visuel d'interfaces web à partir d'une simple description. | M2C4L1 — Prise en main de v0 by Vercel |
| **Vibe coding** | `Défini` | `Méthode / Philosophie` | Manière de créer des logiciels en pilotant des agents IA en langage naturel (français courant), sans avoir à rédiger le code à la main. | M1C1L2 — Qu'est-ce que le Vibe Coding ? |
